## 使用方式

使用 [Obsidian](https://obsidian.md/) 打开本目录即可。笔记使用 Markdown 编写，`.obsidian/` 保存仓库级 Obsidian 配置。

## 目录结构

```text
.
├── Chem Journal/       # 化学学习笔记
├── Phy/                 # 物理学习笔记
├── Math/                # 数学学习笔记，待扩展
├── .obsidian/           # Obsidian 配置
└── README.md            # 项目说明
```

## 注意事项

- 不要把密码、令牌、私钥或其他敏感信息写入笔记。
- `欢迎.md` 是 Obsidian 初始欢迎笔记，后续可以删除或改造成项目首页。
